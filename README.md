the city of dreams
este o aplicație desktop dezvoltată în Java, care permite utilizatorilor să își organizeze obiectivele personale într-un mod creativ și interactiv.
Ideea proiectului este de a transforma fiecare obiectiv într-o clădire dintr-un oraș virtual. Pe măsură ce utilizatorul își actualizează progresul și își îndeplinește obiectivele, orașul se dezvoltă și devine mai bogat în clădiri și elemente vizuale.
Scopul aplicației este de a ajuta utilizatorii să își organizeze obiectivele și să urmărească progresul.
Aplicația va permite:
Adăugarea obiectivelor: utilizatorul poate crea obiective noi
Editarea obiectivelor
Actualizarea progresului
Gestionarea categoriilor
Vizualizarea orașului virtual
Evoluția orașului

Java – limbajul de programare folosit pentru dezvoltarea aplicației.
